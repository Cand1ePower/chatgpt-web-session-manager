# ChatGPT Card Manager v1.1

本地 Chrome / Edge 扩展，用卡片方式浏览、读取、筛选和批量管理 ChatGPT 历史对话。

## v1.1 动画修复

本版重点撤回 v1.0 的独立 `morph proxy` 动画，恢复到 v0.9 的“真实卡片自身 FLIP 展开”方案，再做稳定性优化。

- **展开重新从鼠标悬停的卡片本身开始**：先读取原卡片屏幕坐标，再把同一个 `.cardSurface` 放到最终大卡片尺寸，并通过反向 transform 让动画第一帧与原卡片像素重合。
- 不再创建复制卡片 / 动画代理层，因此不会出现“从别的位置弹出来再展开”的视觉错觉。
- 展开动画约 **340 ms**，收起约 **250 ms**；保留 **0.5 秒**悬停触发延迟。
- 收起时如果鼠标在展开过程中提前移走，会先冻结当前可见位置，再从当前进度直接反向缩回，不会跳帧。
- 针对旧版末帧文字瞬间压缩的问题增加末帧稳定处理：在释放 Web Animations 的 `fill` 状态前先写入最终 transform；收起完成时先冻结最终 transform，再在同一执行周期恢复卡片原始几何。
- 动画只处理 `transform`，不对 `left / top / width / height` 做 CSS transition，减少布局抖动。

## 保留 v1.0 功能

- 展开内容 Markdown 渲染：标题、粗体、斜体、列表、引用、代码、链接、表格、分隔线。
- 优化后的细滚动条。
- 对话图片缩略图与按需图片 URL 解析。
- 卡片跳转按钮，可打开 ChatGPT 原始对话。
- 垃圾桶删除按钮、自定义 Checkbox。
- `加载 10 / 30 / 50 / 100 / 全部`。
- 加载速度：慢 / 正常 / 快速；快速模式需要风险确认。
- IndexedDB 本地缓存、正文与列表分页解耦、429 熔断、跨标签页请求节流。

## 安装 / 更新

1. 解压 ZIP。
2. 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 新安装：选择“加载已解压的扩展程序”。
5. 从旧版本升级：用 v1.1 文件覆盖旧目录，然后点击扩展卡片上的“重新加载”。
6. 刷新 `https://chatgpt.com/`。

快捷键：`Alt + M` 打开 / 关闭 Chat Deck。

> 扩展使用 ChatGPT 网页自身的内部接口，这些接口不是稳定公开 API，ChatGPT 后续更新网页接口时可能需要同步适配。
