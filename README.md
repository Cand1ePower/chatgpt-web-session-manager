# ChatGPT Card Manager v1.7

本版在 v1.6 基础上继续优化已选择卡片的流光边缘：

- 彩虹流光饱和度轻微提高，但仍保持低饱和、克制的整体风格。
- 边框新增非常轻微且恒定的柔光，不做亮度呼吸或脉冲。
- 流光只做角度旋转，`opacity`、阴影和发光强度保持恒定。
- 旋转改为持续线性运行，约 `3.35s` 一圈，不再出现显示几秒后淡出/消失再重新出现的观感。
- 修复已加载卡片、未加载卡片、hover 与读取中样式可能覆盖选中卡片边框/阴影的问题。
- 选中且正在读取正文时禁用原来的 loading 边缘呼吸动画，避免两套动画叠加。
- 深色 / 浅色模式分别调整边缘亮度与微弱外发光。
- 其余功能和 v1.6 保持一致。

安装：解压后在 `chrome://extensions/` 开启开发者模式并加载已解压的扩展；更新旧版本时覆盖目录后点击“重新加载”，再刷新 ChatGPT 页面。
