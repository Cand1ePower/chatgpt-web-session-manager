# ChatGPT Card Manager v1.4

图片预览交互优化版，基于 v1.3 性能优化版继续修改。

- 点击对话中的图片缩略图不再打开下载链接。
- 图片会在 Chat Deck 页面中央以 Lightbox 方式放大预览，最大约占浏览器页面宽高的 60%。
- 点击图片之外任意区域即可关闭预览。
- 支持 `Esc` 关闭图片预览。
- 预览打开期间不会因为鼠标离开原卡片而触发自动收缩；关闭预览后可继续查看原展开卡片。
- 收缩卡片右下角的图片缩略图也支持同样的页面内预览。
- 保留 v1.3 的按需 Markdown DOM、离屏渲染优化、429 限流保护、本地缓存和加载速度控制。
