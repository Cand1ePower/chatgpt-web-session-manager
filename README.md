# ChatGPT Card Manager v1.5

基于 v1.4 的图片预览和卡片选择视觉优化版。

- 修复部分纵向或高分辨率图片在 Lightbox 中超出浏览器可视区域的问题。图片现在同时受 `60vw / 60vh` 与实际视口安全边距约束，并强制 `object-fit: contain`，保证整张图始终完整可见。
- 点击图片外空白区域只关闭图片预览，不会连带收起已经展开的对话卡片；`Esc` 同样只先关闭图片。
- 已选择卡片的静态边框改为黑 / 白 / 灰渐变流光边缘，保持纯中性色，并有连续流动动画，选择状态更明显。
- 保留 v1.4 的图片缩略图、Markdown 渲染、按需正文 DOM、卡片展开模式、加载速度控制、本地缓存与 429 防护。
