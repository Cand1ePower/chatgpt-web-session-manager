# ChatGPT Card Manager v1.6

本版在 v1.5 基础上只调整已选择卡片的流光边缘效果：

- 黑白灰横向扫光改为**低饱和度彩虹色 `conic-gradient` 环形流光**。
- 流光沿卡片边缘**顺时针连续旋转**，不再是从左到右平移。
- 使用更多渐变色节点降低色彩跳变，并将动画周期调整为约 `3.6s`，视觉更柔和、连续。
- 彩虹色刻意压低饱和度，保持 Chat Deck 现有的深灰、克制视觉，不做高亮霓虹效果。
- 深色 / 浅色模式分别调整亮度与边缘对比度。
- 保留 v1.5 的图片 Lightbox、卡片展开、Markdown、批量管理、本地缓存与 429 防护等全部功能。

安装：解压后在 `chrome://extensions/` 开启开发者模式并加载已解压的扩展；更新旧版本时覆盖目录后点击“重新加载”，再刷新 ChatGPT 页面。
