# ChatGPT Card Manager v0.9

本地运行的 Chrome / Edge Manifest V3 扩展，用卡片方式批量浏览、读取和管理 ChatGPT 历史对话。

## v0.9 重点改动

### 1. 卡片展开 / 收起进一步提速

保留 v0.7/v0.8 的 compositor-only FLIP 几何变形方式，只缩短动画时长和内容渐入时间：

- 展开：约 500ms → **380ms**；
- 收起：约 360ms → **280ms**；
- 详情内容渐入：约 340ms → **240ms**；
- 展开内容延迟：约 140ms → **80ms**；
- 背景轻微模糊的进入也同步加快。

悬停触发延迟仍保持 500ms，避免快速划过卡片时误展开。

### 2. 已加载卡片改为更明显的“完成边缘”

已读取正文的卡片不再只依赖“已加载”小字，而是在卡片边缘增加更明显的双层完成态：

- 更清晰的外边框；
- 额外的 1.5px 渐变高光边缘；
- 内侧细高光；
- 鼠标悬停时边缘对比度和阴影轻微增强；
- 深色 / 浅色主题分别适配。

因此快速扫卡片时，带有完整渐变边缘的卡片就是已经读取并缓存正文的对话。

### 3. 未加载卡片改成灰色渐变占位线

未读取正文的卡片不再显示：

- “未加载”；
- “等待读取”；
- “正文尚未加载”；
- “未加载卡片”等提示文本。

折叠状态下只保留标题和创建时间，正文区域使用三条灰色渐变圆角线作为占位，视觉接近常见 Skeleton placeholder：

- 第一条约 86%；
- 第二条约 68%；
- 第三条约 45%；
- 未开始读取时为静态渐变；
- 真正开始请求正文后才切换为 shimmer + spinner 的读取动画。

这样“还没读”的状态可以靠视觉直接判断，不再占用文字空间。

### 4. 状态文字进一步简化

- 已加载：通过卡片边缘表达，不再显示“已加载”胶囊；
- 未加载：仅显示灰色渐变占位线；
- 正在加载：仍显示“读取中”和动态骨架，避免无法判断任务是否正在执行。

## 保留功能

- 正文加载和卡片列表分页互不阻塞。
- 加载 10 / 30 / 50 / 100 / 全部，且 N 指 N 个尚未读取正文的对话。
- 500ms 悬停触发展开。
- 6～9 张普通卡片大小的大型浮动阅读视图。
- 展开不挤占 Grid，周围内容轻微模糊。
- IndexedDB 本地正文缓存。
- 真实创建时间优先，必要时回退最早消息时间。
- 单条删除、批量选择、批量归档、批量删除。
- 429 醒目提示与冷却保护。
- Alt + M 打开 / 关闭。

## 安装 / 更新

1. 解压 ZIP。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”。
4. 首次安装：选择“加载已解压的扩展程序”。
5. 更新：用 v0.9 目录替换旧扩展目录，然后点击“重新加载”。
6. 刷新 `https://chatgpt.com/`。
