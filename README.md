# ChatGPT Card Manager v0.2

本地运行的 Chrome / Edge Manifest V3 扩展，用卡片方式批量管理 ChatGPT 历史对话。

## v0.2 交互优化

- 悬停 **500ms 后**才展开，避免鼠标扫过页面时卡片频繁跳出。
- 展开卡片采用覆盖层方式，**不会撑高 Grid 或挤动其他卡片**。
- 展开时其余卡片只做约 1.6px 的轻微背景模糊，当前卡片保持清晰。
- 卡片进入视口/悬停后立即懒加载正文；加载阶段显示旋转指示器和 shimmer 骨架动画。
- 折叠状态直接显示“开始 / 最近”两个信息片段。
- 展开后增加“对话速览”：开始、最近、末次回复、提问/回复次数和文本量。
- 长消息默认压缩高度，可单独“展开这条消息”，减少滚动成本。
- 创建时间读取更健壮：兼容秒时间戳、毫秒时间戳、ISO 字符串以及多种字段名；详情接口返回后会用会话创建时间或最早消息时间补全。
- 靠近内容区底部的卡片会向上展开，尽量避免超出可视区域。

## 其他功能

- 对话列表按 24 条一批读取，并在接近底部时自动继续加载。
- 正文最多 4 个请求并发。
- 双击标题在新标签页打开原对话。
- 单条删除、多选、批量归档、批量删除。
- 搜索已加载标题和已经懒加载的正文。
- 无服务器、无遥测、无第三方依赖。
- `Alt + M`（Windows）/ `Option + M`（macOS）打开或关闭。

## 安装 / 更新

1. 解压 ZIP。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”。
4. 首次安装：点击“加载已解压的扩展程序”，选择 `chatgpt-card-manager` 文件夹。
5. 已安装 v0.1：用新文件覆盖原目录后，在扩展页点击该扩展的“重新加载”。
6. 刷新 `https://chatgpt.com/`。

## 工作方式

扩展只在 `chatgpt.com` 页面运行，并复用当前浏览器登录会话。当前使用 ChatGPT Web 的内部接口：

- `/api/auth/session`
- `/backend-api/conversations`
- `/backend-api/conversation/{id}`
- `PATCH /backend-api/conversation/{id}`

这些并非稳定公开 API，ChatGPT Web 改版后可能需要同步适配。
