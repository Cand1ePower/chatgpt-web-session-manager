# ChatGPT Card Manager v1.0

本地 Chrome / Edge 扩展，用卡片方式浏览、读取、筛选和批量管理 ChatGPT 历史对话。

## v1.0 主要更新

- **修复卡片展开/收起末帧文字缩小闪烁**：动画改为独立 morph proxy。真实卡片文字始终以原生字号渲染，代理层只负责几何形变，并在末段与真实卡片交叉淡入淡出。
- 展开约 **300 ms**、收起约 **230 ms**，仍保留 0.5 秒悬停触发延迟。
- 展开对话支持基础 **Markdown 渲染**：标题、粗体/斜体、列表、引用、代码块、行内代码、链接、表格、分隔线。
- 优化展开区域和主列表的滚动条：窄轨道、半透明圆角滑块、悬停增强。
- 支持对话中的 **图片缩略图**：识别 `image_asset_pointer`、常见图片附件和直接图片 URL；展开卡片时按需解析签名下载 URL，避免后台批量请求图片。解析成功后，折叠卡片也会保留首图小缩略图。
- 右上角新增 **跳转按钮**：在独立浏览器弹窗中打开 ChatGPT 原始对话。
- 删除按钮改为垃圾桶图标。
- 左上角选择框改为自定义圆角 Checkbox，并增加选中动画。
- 加载按钮简化为 `加载 10 个 / 30 个 / 50 个 / 100 个 / 全部`，不再显示“未加载”字样，也移除了按钮前的圆圈。
- 加载数量菜单新增二级 **加载速度**：
  - 慢：约 4.5 秒 / 条（原保守方案）
  - 正常：约 1.8 秒 / 条
  - 快速：约 0.9 秒 / 条，并保留最低请求间隔
- 选择快速模式会显示醒目风险确认框；未确认时不会执行快速批量加载。
- 保留 IndexedDB 本地缓存、列表与正文加载解耦、429 熔断、Retry-After、跨标签页请求协调等机制。

## 图片说明

图片不会在所有卡片加载时自动批量解析，因为每个 `file-service://...` 资源通常还需要一次签名 URL 请求。v1.0 采用按需策略：展开含图片的对话后才解析缩略图，并在当前页面内缓存解析结果，以减少 429 风险。

旧版本缓存中的消息没有保存图片描述字段。v1.0 在第一次展开这类旧缓存对话时会按限速策略刷新一次详情，以补齐图片信息。

## 安装 / 更新

1. 解压 ZIP。
2. 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 新安装：选择“加载已解压的扩展程序”。
5. 从旧版本升级：用 v1.0 文件覆盖旧目录，点击扩展卡片上的“重新加载”。
6. 刷新 `https://chatgpt.com/`。

快捷键：`Alt + M` 打开 / 关闭 Chat Deck。

> 扩展使用 ChatGPT 网页自身的内部接口，这些接口不是稳定公开 API，ChatGPT 后续更新网页接口时可能需要同步适配。
