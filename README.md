# ChatGPT Card Manager v0.3

本地运行的 Chrome / Edge Manifest V3 扩展，用卡片方式批量管理 ChatGPT 历史对话。

## v0.3 主要变化

- 悬停仍为 **500ms 后展开**。
- 展开卡片改为真正的大型浮层，尺寸会根据当前网格自动计算为约 **3 列 × 2~3 行卡片**，即约 6~9 张普通卡片的面积。
- 浮层会尽量以原卡片为中心，并自动限制在内容区内部，不再挤动 Grid。
- 展开状态采用双栏阅读：左侧“对话速览”，右侧完整消息时间线，长对话阅读面积显著增加。
- 其他卡片仅做轻微模糊，浮层保持清晰。

## 429 / Too Many Requests 防护

v0.2 在卡片进入视口时会同时预取大量详情，容易触发 ChatGPT Web 内部接口的限流。
v0.3 改为：

- 正文详情最大并发从 4 降为 **1**。
- 两次详情请求之间至少间隔约 **1.1 秒**。
- 后台预取队列最多保留 **8** 个当前附近的卡片，离开视口会从后台队列移除。
- 鼠标悬停 500ms 后需要展开的卡片会提升到最高优先级。
- 收到 HTTP `429` 时读取 `Retry-After`（如果服务端返回），否则使用指数退避等待。
- 429 冷却时间默认从约 8~10 秒开始，连续触发时逐步延长，最长约 90 秒，并自动重试。
- 批量删除/归档的请求间隔从 180ms 增加到 **800ms**，写操作也会自动处理 429。

## 创建时间

仍优先读取会话 `create_time`，并兼容秒/毫秒/ISO 时间和多种字段名。如果列表接口没有创建时间，会使用详情接口的创建时间或最早一条消息的时间补全。

## 安装 / 更新

1. 解压 ZIP。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”。
4. 首次安装：点击“加载已解压的扩展程序”。
5. 已安装旧版：覆盖旧目录后，在扩展页点击“重新加载”。
6. 刷新 `https://chatgpt.com/`。

> 如果旧版已经触发 429，服务端限流不会因为更新扩展立即消失。更新到 v0.3 后先等待一小段时间再打开 Chat Deck；v0.3 后续会自行限速和退避。

## 注意

扩展复用当前 ChatGPT 网页登录态，并使用 ChatGPT Web 内部接口。这些并非稳定公开 API，网页接口变更后可能需要同步适配。
