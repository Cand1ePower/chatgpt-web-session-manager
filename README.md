# ChatGPT Card Manager v0.8

本地运行的 Chrome / Edge Manifest V3 扩展，用卡片方式批量浏览、读取和管理 ChatGPT 历史对话。

## v0.8 重点改动

### 1. 卡片列表与正文读取彻底解耦

现在点击 **“加载 N 个未加载”** 后，正文仍然保持单并发、限速读取，但不会再锁住历史会话列表。

- 批量正文正在读取时，仍可继续向下滚动。
- 接近底部后仍会自动调用列表分页接口，继续补充新的对话卡片。
- “加载更多列表”按钮在正文批量读取期间仍然可用。
- 列表请求与正文详情请求走各自的节流通道，并继续共享最低全局请求间隔，降低 429 风险。
- 列表分页发生时，内容区底部会出现独立的三点加载动画 **“正在继续加载卡片列表…”**，不会与正文进度混在一起。

因此现在可以一边让 30 / 50 / 100 个正文慢慢加载，一边继续浏览更早的历史卡片。

### 2. “加载 N 个”改为真正加载 N 个未加载项

旧逻辑会从当前列表开头取前 N 个，因此已经加载过的卡片会占用名额。

v0.8 改为：

1. 跳过已经加载正文的卡片；
2. 跳过当前正在读取、已在详情队列中的卡片；
3. 从剩余的 **未加载卡片** 中继续取 N 个；
4. 如果当前列表中的未加载卡片不足 N 个，会先继续分页拉取更多卡片元数据；
5. 再把新找到的未加载卡片加入正文读取队列。

例如第一次加载 10 个后，再点击“加载 10 个未加载”，会继续读取第 11～20 个未加载对话，而不是重新从前 10 个开始。

“全部”现在也表示 **全部未加载**。

### 3. 删除“加载当前页”

底部不再保留“加载当前页”按钮，操作区更简洁，只保留：

- 加载 N 个未加载；
- 加载更多列表；
- 归档所选；
- 删除所选。

### 4. 未加载卡片视觉状态加强

尚未读取正文的卡片现在不再只靠“正文未缓存”文字区分，而是同时增加：

- 轻微斜纹背景；
- 左侧细状态边；
- 更明显的 **“未加载”** 状态胶囊；
- 空心状态圆点；
- “正文尚未加载”的提示区域；
- 开始读取后，状态边和圆点会进入轻量脉冲动画；
- 成功读取后自动切换为较弱的“已加载”状态，并恢复普通卡片背景。

这样快速扫大量卡片时，可以直接判断哪些正文还没有读过。

### 5. “加载 N 个”选择器重做

删除浏览器原生 `<select>`。原生下拉框在 Chrome / Edge、深色模式和 Shadow DOM 下的选项样式不稳定，也是之前列表显示异常的主要来源。

v0.8 使用自绘组合控件：

- 主按钮直接显示 `加载 10 个未加载`；
- 右侧独立下拉箭头；
- 下拉菜单从按钮上方向上平滑展开；
- 菜单使用缩放 + 位移动画；
- 当前选项有选中标记；
- 每个数量增加简短说明；
- 选项仍为 10 / 30 / 50 / 100 / 全部未加载；
- 批量读取期间主按钮显示旋转状态效果；
- 点击控件外部或按 Esc 可以关闭菜单。

## 保留功能

- 500ms 鼠标悬停后展开。
- 6～9 张普通卡片大小的大型浮动阅读视图。
- v0.7 的 compositor-only FLIP 展开/收起动画。
- 展开时其他卡片轻微模糊。
- 左侧“对话速览”与右侧消息时间线。
- IndexedDB 本地正文缓存。
- 创建时间优先读取真实 `create_time`，必要时回退最早消息时间。
- 单条删除、批量选择、批量归档和批量删除。
- 429 醒目提示与冷却保护。
- Alt + M 打开/关闭。

## 当前限流策略

- 正文并发：1。
- 普通正文请求最小间隔约 3.2 秒。
- 手动批量正文请求额外保证约 4.5 秒间隔。
- 会话列表请求最小间隔约 1.8 秒。
- 列表与详情可以交错进行，但仍共享最低全局间隔，避免短时间 burst。
- 删除 / 归档最小间隔约 2.2 秒。
- ChatGPT 返回 429 后立即停止本轮批量详情任务，并显示“请求过多，请稍后再试”。

> ChatGPT 网页内部 `/backend-api/...` 接口不是公开稳定 API，因此 OpenAI 没有公布固定的网页历史接口请求配额。扩展只能通过节流、缓存、队列和熔断尽量降低 429 概率。

## 安装 / 更新

1. 解压 ZIP。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”。
4. 首次安装：选择“加载已解压的扩展程序”。
5. 更新：用 v0.8 目录替换旧扩展目录，然后点击“重新加载”。
6. 刷新 `https://chatgpt.com/`。
