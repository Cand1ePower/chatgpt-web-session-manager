# ChatDeck Demo Visual Identity

## Style Prompt

Quiet product-documentary motion: a graphite workspace frames a warm paper-like card surface, with cobalt used as the active interface signal and a small chartreuse note for emphasis. The visual language should feel like a precise tool being opened and understood, not a neon software advertisement. Keep the interface legible, asymmetrical, and generous around the key message.

## Colors

- `#111318` — graphite background
- `#F4F1EA` — paper surface
- `#1B1D24` — primary ink
- `#6878FF` — cobalt interaction accent
- `#D9F36C` — small signal highlight

## Typography

- Headlines: `Microsoft YaHei`, sans-serif, 900 weight.
- Supporting copy and UI labels: `Cascadia Mono`, `Microsoft YaHei`, monospace, 400–700 weight.

## Motion

Use confident entrances, one calm ambient movement per scene, and restrained crossfades / wipes between scenes. The first message should arrive before secondary labels.

## What NOT to Do

- No generic blue-purple gradient backgrounds.
- No repeated equal-size dashboard tiles as the main composition.
- No tiny web-sized text in the video.
- No fake personal conversations or real account data in demo captures.
